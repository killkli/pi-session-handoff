# 交接（HANDOFF）

> 本檔於每次 session 收尾時**整份重寫**（`/wrap`），不要追加。
> 「下一步」第 1 項即開工入口；沒有內容的段落寫「無」；總長度 ≤ 80 行。

## 目標

這條工作線的最終目標（一兩句）。

## 本次完成

- 具體做了什麼，附檔案路徑或 commit hash

## 進行中（未完成）

- 停在哪個檔案、哪個函式，做到幾成

## 下一步（依優先序）

1. 第一個要做的具體動作，下一個 session 可以直接開工

## 已決定的事與理由

- 決策 → 理由（避免下次重新討論）

## 死路（試過不行的）

- 方法 → 為什麼失敗（避免下次重踩）

## 待我確認

- 需要人決定的事項

## 驗證狀態

- 最後跑的指令與結果；沒跑就寫「未跑」

---

寫完請刪掉這段提醒：

- 只寫本 session 實際發生、可驗證的事；commit hash 與路徑先用
  `git log --oneline -n 20` 與 `git status --short` 核對過。
- 「死路」最有價值：試過又放棄的做法一定要寫，附失敗原因。
- 只屬於某個模組的不明顯知識，同步補進該模組目錄的 `AGENTS.md`，不要只留在交接檔。
